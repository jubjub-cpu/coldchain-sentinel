# Release Notes

## v1.0.0 - Initial public release

- Added four deterministic synthetic cold-chain drills with 188 generated readings.
- Added multivariate temperature, humidity, battery, signal, door, cadence, and route-stage evidence.
- Added duration-aware temperature and humidity alerts with persistence and clear hysteresis.
- Added visible single-spike suppression and policy sensitivity controls.
- Added sensor-gap, low-battery, and weak-signal findings.
- Added Canvas telemetry timeline and scrollable raw reading ledger.
- Added required-note human acknowledgement and escalation workflow.
- Added local JSON incident export with limitations and separate human decision fields.
- Added engine, static, desktop, mobile, failure-state, privacy, and deployment validation.
